(i) GAUSSIAN RANDOM FIELD (GRF) SAMPLING:
--------------------------------------------------------------------------------
- Spectrum Covariance Operator:
  C = (-Delta + tau^2 * I)^(-s) on periodic 1D domain [0, 2*pi).
  Parameters: tau = 3.0, s = 2.0.
  Continuous Fourier amplitude:
    A(k) = (k^2 + tau^2)^(-s / 2) = (k^2 + 9)^(-1.0)
  Mean mode: A(0) = 0.0 (strictly enforces zero mean in frequency space).
- Random Sampling:
  k = 2*pi * rfftfreq(N, d=L/N) = [0, 1, ..., N//2] (integer wavenumbers for L=2*pi).
  Complex Gaussian coefficients:
    c_k = real_k + 1j * imag_k, where real_k, imag_k ~ Normal(0, 1).
    Hermitian symmetry constraints for real-valued fields: imag[:, 0] = 0.0 and imag[:, -1] = 0.0.
- Normalization in Fourier Space:
  u_hat(k) = c_k * A(k) * (N / sqrt(2.0)).
- Spatial Realization:
  u(x) = irfft(u_hat, n=N).
- Spatial Rescaling / Standardisation:
  u <- (u - mean(u)) / (std(u) + 1.0e-8).
  Every realized sample strictly has spatial mean = 0.0 and sample variance = 1.0.
- Seed Handling:
  torch.manual_seed(seed) is set immediately prior to randn drawing.

(ii) PREPARE INITIAL CONDITIONS PER SYSTEM:
--------------------------------------------------------------------------------
Initial condition transformations from standardized u_grf:
- S1 (Space-Fractional Burgers):
    u_0(x) = 0.5 * u_grf(x)
    Produces smooth, mean-zero wave profiles with typical amplitude in [-1.5, 1.5].
- S2 (Fractional Allen-Cahn):
    u_0(x) = tanh(u_grf(x))
    Produces two-phase phase-field states bounded strictly in (-1, 1) with steep interfaces.
- S3 (Linear Fractional Diffusion):
    u_0(x) = u_grf(x)
    Produces zero-mean temperature / concentration distributions.
- S4 (Fractional Fisher-KPP):
    u_0(x) = sigmoid(u_grf(x)) = 1 / (1 + exp(-u_grf(x)))
    Produces strictly positive population density fields bounded in (0, 1).

(iii) PDE SOLVER SETTINGS PER SYSTEM:
--------------------------------------------------------------------------------
- Domain & Spatial Discretization:
    Domain: periodic interval [0, 2*pi).
    Native Grid: N = 256 equidistant points for dataset generation across all systems (S1, S2, S3, S4).
    Native Time Step: dt = 1.0e-3 (1000 integration steps to T = 1.0).
    De-aliasing: 2/3-rule Orszag spectral mask (modes with |k| >= N/3 are zeroed) for non-linear advection and reaction.
    Reference Grid & Step: N_ref = 512, dt_ref = 5.0e-4 (2000 steps), used strictly for numerical self-convergence verification and zero-shot super-resolution testing.

- S1 (Space-Fractional Burgers):
    Equation: d_t u + u * d_x u + nu * (-Delta)^(alpha/2) u = 0.
    Dissipation constant: nu = 0.05.
    Solver Method: Strang-splitting Integrating-Factor pseudo-spectral solver.
    Linear Step: Exact exponential integrating factor E_half = exp(-nu * |k|^alpha * dt / 2).
    Nonlinear Step: Classical 4th-order Runge-Kutta (RK4) on the advective flux
      f(u) = -0.5 * d_x(u^2) computed pseudo-spectrally with 2/3 Orszag dealiasing.

- S2 (Fractional Allen-Cahn):
    Equation: d_t u + eps^2 * (-Delta)^(alpha/2) u - (u - u^3) = 0.
    Interfacial thickness constant: eps^2 = 0.01 (eps = 0.1).
    Solver Method: Strang-splitting Integrating-Factor pseudo-spectral solver.
    Linear Step: Exact exponential factor E_half = exp(-eps^2 * |k|^alpha * dt / 2).
    Nonlinear Step: RK4 on the bistable polynomial reaction f(u) = u - u^3.

- S3 (Linear Fractional Diffusion):
    Equation: d_t u + nu * (-Delta)^(alpha/2) u = 0.
    Diffusion constant: nu = 0.1.
    Solver Method: Exact closed-form Fourier spectral multiplier:
      u_hat(k, T) = u_hat(k, 0) * exp(-nu * |k|^alpha * T).
      Zero temporal discretization error.

- S4 (Fractional Fisher-KPP):
    Equation: d_t u + nu * (-Delta)^(alpha/2) u - r * u * (1 - u) = 0.
    Reaction & diffusion constants: nu = 0.1, r = 1.0.
    Solver Method: Strang-splitting integrating factor + RK4 on f(u) = u * (1 - u).

- Reference Convergence:
    Relative temporal self-convergence ||u(dt) - u(dt/2)||_2 / ||u(dt/2)||_2 < 1.0e-5.
    Spatial self-convergence ||u(N=256) - u(N=512)||_2 / ||u(N=512)||_2 < 1.0e-4.

(vi) EVALUATION METRIC CLARIFICATION:
--------------------------------------------------------------------------------
- Question: Is relative L2 error the norm over the whole test set (aggregate) or
  the mean of per-sample ratios?
- Answer: AGGREGATE NORM OVER THE ENTIRE TEST SET.
- Exact Code Lines in fr_fno_master.py (Lines 1583-1586):
    diff_norm = torch.norm(pred_test - y_test)
    true_norm = torch.norm(y_test) + 1.0e-10
    test_rel_l2 = (diff_norm / true_norm).item()
  Here, pred_test and y_test are 3D tensors of shape (200, 1, 256).
  torch.norm() calculates the Frobenius / L2 norm across all 200 samples and all
  256 spatial coordinates simultaneously:
    sqrt(sum_{i=1}^200 sum_{x=1}^256 (pred_{i,x} - y_{i,x})^2) / sqrt(sum_{i=1}^200 sum_{x=1}^256 y_{i,x}^2)
  This is the standard definition used by Li et al. (2021) in the original FNO paper.
